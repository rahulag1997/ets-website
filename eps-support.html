EPS Support

Last updated: 1 October 2026

Help for Easy PDF Solutions on Android, iOS, and desktop (macOS, Windows, Linux).

Contact us

Email support@etsproducts.in. Please include:

  • your platform — Android, iOS, macOS, Windows, or Linux;
  • the app version, shown in the app's settings/about area;
  • which tool you were using, what you did, and what you expected instead. A sample input file helps if you can share one (remove any sensitive content first).

We aim to reply within a few business days.

Common questions

Where are my processed files saved?

On desktop, you choose the folder in a save dialog; the app remembers the last folder you used. On mobile, you save to your files app or share the result directly from the app.

Did EPS change my original file?

No. Every tool writes a new file. The PDF (or image) you started from is never overwritten.

Does EPS work offline?

Yes, entirely. It makes no network connection at all, and on Android it does not request internet access.

Remove Password says the password is wrong, but I'm sure it's right

Check for trailing spaces or autocorrect/autocapitalisation changes if you typed it on mobile. Some PDFs have a separate "owner" password (which restricts printing/editing) and a "user" password (needed to open it) — Remove Password needs whichever password actually opens the file.

Can EPS add a password to a PDF?

Not in this version — EPS can remove a password from a PDF you already have the password for, but adding one isn't supported yet.

Form filling and annotations aren't in this version

Basic form filling and text/annotation editing are planned for a future release and aren't available yet.

Compress made my PDF's text unselectable

Compress works by re-rendering each page as an image at a lower quality, which shrinks file size well for scans and photo-heavy PDFs but means the output is image-based, not searchable/selectable text. If you need to keep selectable text, don't run Compress on a text-based PDF.

What data does EPS collect about me?

None. See the EPS Privacy Policy.
